# AgriSmart Latacunga

## Objetivo
Desarrollar una infraestructura IoT para el monitoreo
de variables agrícolas mediante sensores, MQTT y
servicios de procesamiento de datos.

## Equipo de trabajo

| Integrante | Rol |
|---|---|
| Integrante 1 | Infraestructura |
| Integrante 2 | Datos |
| Integrante 3 | Seguridad |
| Integrante 4 | Documentación |

## Hitos
- H1: Nodo sensor y broker MQTT.
- H2: Gateway edge y nube.
- H3: Red y virtualización.
